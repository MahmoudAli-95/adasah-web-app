## 📖 عن المشروع | About The Project

### 🇸🇦 العربية
**عدسة** هي منصة رقمية متكاملة مخصصة للمصورين وعشاق التصوير الفوتوغرافي. تهدف المنصة إلى تقديم مقالات تعليمية وشروحات شاملة لمفاهيم التصوير مثل مثلث التعريض، اختيار العدسات، ومعالجة الصور، بتصميم عصري ومتجاوب يدعم اللغة العربية بالكامل (RTL).

### 🇬🇧 English
**Adasah** is a modern, fully responsive web application and blog built for photography enthusiasts and professionals. It offers comprehensive articles, camera setup guides, and photography tips with a clean UI, seamless navigation, and RTL support.

---

## ✨ المميزات الرئيسية | Key Features

- 🔍 **Real-time Search & Filter:** بحث سريع وتصفية المقالات حسب الأقسام والتصنيفات.
- 📱 **Fully Responsive:** تصميم عصري ومتجاوب مع جميع الشاشات (الهواتف، الآيباد، الشاشات الكبيرة).
- ⚡ **Fast Performance:** سرعة فائقة في التحميل باستخدام Vite و React Router.
- 🎨 **Modern Dark UI:** واجهة مستخدم مظلمة مريحة للعين مع تأثيرات جرافيك أنيقة بـ Tailwind CSS.
- 👨‍💻 **Authors Section:** عرض فريق الكتاب والمصورين وتفاصيل كل كاتب.

---

## 🛠️ التقنيات المستخدمة | Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Build Tool:** Vite
- **Icons:** FontAwesome / Custom SVG
